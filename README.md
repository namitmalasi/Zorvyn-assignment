# Finance Dashboard

- A simple financial dashboard built with React to help users track transactions, understand spending patterns, and visualize financial data.

## Features

- Dashboard Overview
- Transactions
- Role-Based UI
- Insights

## Tech Stack

React.js
Zustand
Tailwind CSS
Recharts

## Setup

git clone https://github.com/namitmalasi/Zorvyn-assignment.git
cd finance-dashboard
npm install
npm run dev
